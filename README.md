# DDT — 典当通 Linux 适配与会计辅助工作台

**公开源码正在分批迁移；当前仓库不是完整可安装客户端，也不是典当通官方产品。**

## 当前已经提交的内容

- `client/java/`：20份自写 Java 兼容与诊断源码，含 Linux 系统信息、浏览器生命周期、窗口观察、JFR 退出记录及探针。
- `ci/`：不加载商业客户端的独立 SWT/GTK/WebKit 平台测试；仅下载摘要固定并严格验签的 Eclipse 公开依赖。
- `tools/check_public_tree.py`：公开分发检查，阻止常见密钥、运行目录、商业二进制和字体等误提交。
- `tests/`：发布边界测试和使用真实 JDK 的合成退出场景测试。

**尚未全部上传：Python 部署/升级模块、会计工作台前后端及完整集成测试。** 不以本批提交宣称完整源码迁移完成。

## 测试

```bash
python3 tools/check_public_tree.py
python3 -m unittest discover -s tests -v
```

JFR测试使用本机JDK、临时目录及合成进程；不加载原客户端。缺JDK时显式跳过，不冒称验证成功。

GitHub工作流使用 `ubuntu-24.04` 标准运行机和只读仓库权限，关闭 checkout 凭据持久化。平台任务只打开本地合成页面，既不登录厂商，也不调用模型；不关闭 AppArmor 或浏览器沙箱，不上传运行截图、JFR、商业文件或原始日志。系统包安装只作用于一次性测试虚拟机。

**必须取得实际 run ID 和成功结果，才能报告云端通过。工作流文件存在不是运行证据。** 公开平台通过也不等于原客户端登录、业务报表、目标机GPU/输入法或正式会计验收通过。

## 禁止公开的内容

典当通 EXE、商业 JAR/DLL、由其生成的字节码补丁、客户数据库、会话、许可证、密钥、令牌、字体及原始业务日志。不要将以前的整套私有验收 ZIP 直接上传本仓库或公开 Release。

原客户端完整验收应在另行授权的私有环境执行。公开的适配源码不授予典当通商业软件的运行、修改、转授或再分发许可。本轮没有代用户选择新的开源许可证。

详见 `SECURITY.md` 和 `client/README.md`。
