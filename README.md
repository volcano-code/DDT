# DDT — Linux 客户端适配与会计辅助工作台

本仓库发布自写的典当通 Linux 移植适配工具、会计辅助工作台、测试与 CI 工程。**不是典当通官方客户端，不是厂商开放 API，不是生产会计软件。**

## 公开范围

- `client/`：Python 部署/升级/诊断工具、自写 Java 兼容层和测试。
- `workbench/`：FastAPI + TypeScript + SQLite 的导入、核对、人工复核与辅助凭证草稿原型。
- `integration/`：使用合成数据的跨项目测试；涉及商业客户端的用例仅在有授权的私有环境执行。
- `ci/`、`cloud_eval/`：公开平台/工作台检查与私有客户端验收分离。

**禁止提交**：典当通 EXE、商业 JAR/DLL、由其生成的平台补丁、客户数据、会话目录、许可证、密钥、令牌、字体文件和运行中的数据库。原安装包不上传公开仓库、公开 Release 或公开 Actions artifact。

## 安全说明

公开 CI 只使用自写代码、合成样例与经校验的公开依赖，不下载或执行商业客户端，不自动连接厂商服务，不调用付费模型，不执行付款或正式记账。

原程序仍保有账户本身的权限；适配层不是业务只读控制器。网络命名空间隔离也不等于完整文件系统沙箱。无效签名、缺依赖或被阻断的测试不得标记为通过。
